# 🐱 Cat Shelter API

A RESTful API built using ASP.NET Core and SQL Server.

---

## Features

- Get all cats
- Get a cat by ID
- Add a new cat
- Update a cat
- Delete a cat

---

## Technologies

- ASP.NET Core
- C#
- SQL Server
- REST API

---

## Project Structure

Controllers/
Models/
Program.cs
appsettings.json

---

## Getting Started

Clone the repository

Update the SQL Server connection string in appsettings.json

Run the application

---

## API Endpoints

GET /api/cats

GET /api/cats/{id}

POST /api/cats

PUT /api/cats/{id}

DELETE /api/cats/{id}
